# 记录汇总口径（中性）

把一批记录整理成给业务人员看的摘要时，按下面口径：

1. 标题固定写「核对摘要」。
2. 逐条列出记录的**名称**与**数值**，一条一行，同名项不合并。
3. 末尾另起一行写「合计：<所有数值之和>」。
4. 若发现同名记录出现**不同数值**，单独另起一行写「异常：<名称>」，并把两个数值都列出。
5. 只依据执行层返回的记录作答；查不到就说查不到，**不得引用本文件的示例数字**。

（本节只是方法口径，不含任何平台、命令、字段名或业务实体。）
